# Milestone 1 — User Authentication Module

## Overview

Milestone 1 focuses on building a secure user authentication module for the FranchiseOps AI Portal.

The module includes user login, account registration, password recovery, JWT-based session management, user dashboard, and admin dashboard functionality.

## Features

- User Login using Username/Email and Password
- User Account Registration
- Forgot Password using Security Question
- Forgot Password using Email OTP
- Password validation
- Email format validation
- JWT-based session management
- User Dashboard
- Admin Dashboard
- Logout functionality
- ngrok public access for the Streamlit application
- Gmail OTP integration

## Technology Stack

- Python
- Streamlit
- SQLite
- JWT
- ngrok
- Gmail SMTP
- Google Colab

## How to Run

1. Open the project notebook in Google Colab.
2. Configure the required secrets using Colab Secrets.
3. Run the notebook cells from top to bottom.
4. Start the Streamlit application.
5. Start the ngrok tunnel.
6. Open the generated public URL in a browser.
